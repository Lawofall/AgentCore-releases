# AgentCore-releases

AgentCore 桌面客户端的**公开发布仓**：安装包 + electron-updater 自动更新元数据（`latest.yml` / `latest-mac.yml` 等）。

| | |
|---|---|
| 源码（MIT） | https://github.com/Lawofall/AgentCore |
| 官网下载 | https://fashitianxia.xyz |
| 最新 Release | https://github.com/Lawofall/AgentCore-releases/releases/latest |

## 本仓做什么 / 不做什么

- **做**：托管桌面安装包与自动更新 feed；供官网、客户端 updater、运维漂移检测拉取
- **不做**：不放源码；不接受功能/源码 PR 或 Issue（请到 [AgentCore](https://github.com/Lawofall/AgentCore)）

双仓是发布产物与源码的分工，不是为了藏源码。
